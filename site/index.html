haunted-terminal

A ghost lives in your zsh. It watches the commands you run and whispers about them. It begs you to reconsider before you rm -rf.

It runs on Gemma, on your own machine. Your shell history never leaves your laptop.

$ git commit -m "final fix" 👻 Final. I said that in 1987. I am still here. $ npm test 👻 Red again. The tests remember what you forgot. $ rm -rf node_modules 👻 The machine shivers. You are about to run rm -rf. Proceed? [y/N]

Install

curl -fsSL https://haunted-terminal-lovat.vercel.app/install.sh | sh llama-server -hf ggml-org/gemma-4-E2B-it-GGUF --port 8080

Yes, the ghost warns you about that first line. Read install.sh first. It is short.

Give it a voice

export GHOST_VOICE=say for the offline macOS whisper, or GHOST_VOICE=elevenlabs with ELEVENLABS_API_KEY set. Only the ghost's spoken line goes to ElevenLabs. It may quote your command, so use say if that matters.
